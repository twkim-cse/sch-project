## 제한적인 PDF 양성 표본

기존 수동 선정 근거를 재사용하고 같은 ABL PDF 해시와 해당 페이지 원문을 재대조했다.
점검 항목 2~6의 알려진 양성 11개가 **11/11 포함**됐고 예상 후보 태그도 11/11 포함됐다.
원본의 잘못된 조문/특약 메타데이터가 그대로인 상태에서도 본문 신호로 선정됐다.

이는 완전한 정답 집합으로 측정한 재현율이 아니다. ABL 1번의 독립 양성 표본이 없고,
나머지 모든 미선정 조항을 검사하지 않았다. CM295F/Dental은 대응 PDF도 없어 문서 전체 재현율은 미검증이다.
선택된 양성 표본만으로 precision이나 전체 recall을 주장하지 않는다.

## 위험과 다음 검증

- 의료 코드/약어만 있는 표, 일반어·참조만 있는 조항, 멀리 떨어진 예외/공통 머리말은 누락 가능성이 남는다.
- 잘못된 section/article/rider_id로 문맥 확장이 잘못되거나 불필요하게 많아질 수 있다. 본문은 원본 그대로다.
- 검사 중 의료기관/특정감염병 정의의 간접 본문을 놓칠 수 있어 일반화 가능한 의료 제목 규칙과
  참조 규정의 보수적 포함을 추가하고 회귀 검증했다. 특정 보험사/ID 하드코딩은 없다.
- 전체 미선정 조항의 층화 표본을 사람이 검토하고 각 항목의 완전한 양성 집합을 보강해야 한다.
- broad 모드의 후보 수는 ABL 1,893 / CM295F 1,556 / Dental 1,342다. fallback을 적용하면 비용이 다시 늘 수 있다.
- 기존 전체 무손실 계획/실패 체크포인트/재개, 503·504 explain 안정화, B안 OFF, 기존 API 계약은 유지됐다.
- 부분 실패에 대한 merge는 409로 거부한다. 후보 완료는 CANDIDATES_COMPLETE이며 전체 문서 위험 검토 완료가 아니다.
- Java/Spring·프론트·Docker 통합과 실제 Gemini 분류·속도 검증은 별도이며 아직 실행하지 않았다.

안전한 집계 결과는 로컬 `test_results/candidate_filter_offline_summary.json`에 있다.
개별 실제 조항 결정 명세는 Git 제외 local_policy 아래에 있으며 게시하지 않는다.
